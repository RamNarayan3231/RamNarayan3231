## 📌 Featured Projects

### 🧠 1. Smart Research Assistant AI (RAG System)
- **Description:** A Retrieval-Augmented Generation (RAG) system built for semantic document search, question answering, and text summarization.
- **Tech Stack:** Python, LangChain / LlamaIndex, Vector Database (ChromaDB / FAISS), OpenAI / Hugging Face Embeddings, Streamlit.
- **Key Features:**
  - Semantic vector search across multi-format documents (PDFs, TXT, Docs).
  - Contextual Q&A using LLMs with minimal hallucination.
  - Automated document summarization and key insight extraction.

---

### 🔍 2. Truth-Scan (Fake News & Misinformation Detector)
- **Description:** An NLP deep learning pipeline designed to classify news articles and social posts as real or fake.
- **Tech Stack:** PyTorch / TensorFlow, Hugging Face Transformers (BERT), LSTM, NLTK, Streamlit / FastAPI.
- **Key Features:**
  - Fine-tuned BERT model for high-accuracy text classification.
  - Hybrid architecture incorporating LSTM for sequential text modeling.
  - Real-time text verification and confidence score output.

---

### 🏥 3. Pneumonia Detection System
- **Description:** A medical imaging diagnostic tool utilizing Deep Learning architectures to analyze chest X-ray images.
- **Tech Stack:** PyTorch, Torchvision, ResNet-50, DenseNet-121, OpenCV, Flask / Streamlit.
- **Key Features:**
  - Transfer learning with ResNet & DenseNet backbones for accurate classification.
  - Preprocessing pipeline including CLAHE, image normalization, and data augmentation.
  - Visual output indicating normal vs. pneumonia-affected scans.

---

### ⚙️ 4. Conveyor Belt Damage Detection System
- **Description:** Real-time computer vision system built for industrial automated inspection.
- **Tech Stack:** Python, YOLO (You Only Look Once), OpenCV, Streamlit.
- **Key Features:**
  - Real-time video frame object detection and bounding box visualization.
  - Detection of tears, surface cracks, and anomalies on industrial belts.
  - Streamlit dashboard for monitoring live feeds and alert triggers.

### 💬 5. Message Intelligence System (`msgiq`) [Live Demo](https://msgiq-l2.streamlit.app/) 
- **Description:** End-to-end NLP processing and task automation engine.
- **Tech Stack:** Python, Scikit-learn, Hugging Face, Streamlit, Regex.
- **Key Features:**
  - Multi-class text classification for incoming messages.

### 🫀 6. Arrhythmia Detection using Hybrid CNN-LSTM
- **Description:** Research project focused on ECG signal analysis for cardiac arrhythmia classification.
- **Tech Stack:** Python, TensorFlow / Keras, Scipy, NumPy, Matplotlib.
- **Key Features:**
  - Hybrid architecture leveraging 1D-CNN for feature extraction and LSTM for temporal sequence modeling.
  - Signal preprocessing, noise removal, and beat segmentation.
